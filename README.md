# Кубы на плоскости

Небольшой пример на C++ и OpenGL с FreeGLUT. Кубы падают под действием
гравитации, сталкиваются с плоскостью и друг с другом. Физика упрощённая:
кубы остаются выровненными по осям и не вращаются.

## Управление

- `Space`: создать куб над центром плоскости.
- Левая кнопка мыши: создать куб над точкой плоскости под курсором.
- `Esc`: закрыть окно.

## Сборка из терминала

Сборка выполняется в отдельной папке `build/`, которая не добавляется к исходникам:

```bash
cmake -S . -B build
cmake --build build
./build/opengl-cubes
```

## Файлы

- `main.cpp`: запуск приложения.
- `Application.h/.cpp`: окно, ввод и цикл обновления.
- `Renderer.h/.cpp`: камера, плоскость, кубы и выбор точки мышью.
- `Physics.h/.cpp`: гравитация и столкновения.
- `Cube.h`: структуры вектора и куба.
